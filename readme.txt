A clean, fast block theme for agencies, studios and small businesses.

== Description ==

Meridian is a full-site-editing block theme. Every landing-page section is an
editable block pattern, colours and typography live in theme.json, and it ships
with Default, Midnight (dark) and Clay style variations.
